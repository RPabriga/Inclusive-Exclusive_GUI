# Club Membership Calculator

## Inclusion-Exclusion Principle

A simple Python GUI application that calculates the number of **unique students** in different clubs using the **Inclusion-Exclusion Principle**.

The application supports calculations for **two clubs** and **three clubs**.

---

## Features

- Calculate unique students in two clubs
- Calculate unique students in three clubs
- Handle overlapping memberships
- Input validation
- Load sample Case 1
- Load sample Case 2
- Clear all inputs
- Display the calculation formula and result
- Simple dark-themed graphical interface

---

## Requirements

Before running the application, make sure you have:

- Python 3.x
- Tkinter

Tkinter is included with most standard Python installations.
